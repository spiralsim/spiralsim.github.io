# spiralsim.github.io

My personal website / portfolio! I just made a static site based off the Just the Docs Template, so almost all the code can be adapted to your own versions. Additional personal projects are linked on the site.

# Viewing Changes
## Building locally
```
bundle install # May be needed the first time in a dev session
bundle exec jekyll serve
```
Then, see the changes at http://127.0.0.1:4000/.

## Pushing remotely
Commit and push as usual. The changes should appear on the internet in a few minutes.

# Making a GitHub Pages website with Just the Docs
Follow the instructions on the [Just the Docs Template](https://just-the-docs.com/#getting-started).

# Putting the website on a custom domain
I used Cloudflare as my registrar and for CNAME/DNS services.
