# spiralsim.github.io

My personal website / portfolio! I just made a static site based off the [Just the Docs Template](https://just-the-docs.com/#getting-started) in 2024, so almost all the code can be adapted to your own versions. Additional personal projects are linked on the site.

# Viewing Changes
## Building locally
1. If this is the first time in your developer session, you may need to install the bundle:
```
bundle install
```
2. Compile and run the package:
```
bundle exec jekyll serve
```
3. Then, see the changes at http://127.0.0.1:4000/.

## Pushing remotely
Use `git commit` and `git push` as usual. The changes should appear on the internet in a few minutes.
